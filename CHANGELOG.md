# Changelog

## 0.1.0 — 2026-10-24
- First release: `check`, `sync`, `scan` commands and the `load()` Python API.
- Typed schema annotations in `.env.example`: str, int, float, bool, port, url, email, json, choice.
- Secret detection for OpenAI, Anthropic, GitHub, AWS, Google, Slack, Stripe, Hugging Face, Groq, JWTs, private keys and passwords in URLs.
- pre-commit hooks, a reusable GitHub Action and a Docker image on GitHub Packages.
